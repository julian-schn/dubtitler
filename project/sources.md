# Quotation sources

When the recording quotes a text that already has a standard published
translation in the target language, that published wording is **quoted, not
re-translated**. A re-translation of a familiar verse reads as wrong to anyone
who knows it, however accurate it is.

Record here which edition you are quoting, and the verbatim text of each
quotation, so the translator copies rather than reconstructs.

Delete this file if the job has no quotations.
